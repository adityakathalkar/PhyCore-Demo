# PhyCore – Android-Based Physics Learning Application

PhyCore is an Android-based physics learning application developed as a B.Sc. Computer Science academic project. The app is designed to make physics learning interactive and engaging through study materials, quizzes, videos, simulations, and games.

## Features
- User Login & Registration (Firebase Authentication)
- Physics Question Bank
- MCQ Practice Tests
- YouTube Video Learning
- Physics Simulations
- Physics Games
- User-Friendly Interface

## Technologies Used
- Kotlin
- Java
- XML
- Firebase Authentication
- Firebase Firestore
- Android Studio
- YouTube API
